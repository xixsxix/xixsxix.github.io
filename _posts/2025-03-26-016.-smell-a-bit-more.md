## 2. 문법 포인트

### お<ruby>願<rt>ねが</rt></ruby>いがある
"부탁이 있다"는 표현. **お願い(おねがい)**는 "부탁"을 의미하며, **～がある**는 "~이 있다"는 뜻.

### つかめない（掴めない, 못 잡다)
**つかむ（掴む, 잡다, 파악하다)** 의 가능형 부정

### ～ですかね？
"~일까요?"로, 상대의 동의를 구하거나 부드러운 어감을 만들 때 사용

### **<ruby>念写<rt>ねんしゃ</rt></ruby><ruby>的<rt>てき</rt></ruby>な<ruby>感<rt>かん</rt></ruby>じで** : "염사(念写) 같은 느낌으로"
- **念写（ねんしゃ）** : 초능력으로 사진을 찍는다는 개념(초심리학 용어)
- **～的（てき）な** : "~적인"
- **感じ（かんじ）** : 느낌

### <ruby>分<rt>わ</rt></ruby>かるっちゃ<ruby>分<rt>わ</rt></ruby>かる（わかるっちゃわかる)
"알 수 있긴 알겠어" → **分かる（わかる, 알다)** + **っちゃ** → 구어체에서 **だけは**의 축약형, "알 수 있긴 알겠다"는 의미

### <ruby>引<rt>ひ</rt></ruby>きずってた（ひきずってた）
**引きずる（ひきずる, 끌다)** 의 과거 진행형으로 "끌고 다닌"

### わけじゃない
"그런 이유는 아니다" → **わけ（이유, 원인） + じゃない（~이 아니다)**

### <ruby>消<rt>き</rt></ruby>えかかってる（きえかかってる）
**消える（きえる, 사라지다)** 의 진행형과 **かかる（~하게 되다)** 가 결합되어 "사라져 가고 있다"는 의미

### <ruby>上<rt>あ</rt></ruby>げられたり（あげられたり）
**上げる（あげる, 올리다)** 의 가능형으로 "올릴 수 있다" → **たり**는 여러 가지 동작이나 상태를 나열할 때 사용됨.

### しないですかね : "~할 수 없나요?"
- **しない** : **する（하다)** 의 부정형
- **ですかね** : "할 수 있나요?"라는 의미로, 의문과 동시에 상대방의 동의를 구하는 표현

## 3. 주요 단어

[^1]: **力 (ちから, chikara)** : 힘

[^2]: **持ち去る (もちさる, mochisaru)** : 가지고 가버리다, 훔쳐 가다

[^3]: **証拠 (しょうこ, shouko)** : 증거

[^4]: **例えば (たとえば, tatoeba)** : 예를 들어

[^5]: **部屋の中を** : "방 안을" → **部屋（へや, 방）+ の中（なか, 안)"**

[^6]: **写真撮って** : "사진을 찍어서" → **写真（しゃしん, 사진）+ 撮る（とる, 찍다）의 연결형**

[^7]: **運んでる（はこんでる)** : 運ぶ（はこぶ, 나르다, 옮기다）의 진행형(運んでいる → 구어체에서 い 생략)

[^8]: **写し出す (うつしだす, utsushidasu)** : 비춰내다, 투영하다, 보여주다

[^9]: **できない (できない, dekinai)** : 할 수 없다

[^10]: **もう (もう, mou)** : 이미, 벌써

[^11]: **じゃん (じゃん, jan)** : ~잖아 (구어체에서 강조나 친근감 표현)

[^12]: **元々ある（もともとある）** : "본래 있는" → **元々（もともと, 본래) + ある（있다)**

[^13]: **引き上げる（ひきあげる）** : "끌어올리다, 향상시키다"

[^14]: **だけだからさ** : "일뿐이니까" → **だけ（~일 뿐） + だから（~이니까)**

[^15]: **におい (におい, nioi)** : 냄새

[^16]: **基板 (きばん, kiban)** : 기판

[^17]: **熱せられた (ねつせられた, netsuserareta)** : 열을 받았다

[^18]: **ホコリ (ほこり, hokori)** : 먼지

[^19]: **混ざった（まざった）** : **混ざる（まざる, 섞이다)**의 과거형으로 "섞인"

[^20]: **残ってる（のこってる）** : **残る（のこる, 남다)**의 진행형으로 "남아 있다"

[^21]: **かなり** : 상당히, 꽤

[^22]: **難しい (むずかしい, muzukashii)** : 어려운

[^23]: **かすかに** : 미세하게, 희미하게

[^24]: **残り香（のこりが）** : 남은 향기

[^25]: **だいぶ (だいぶ, daibu)** : 꽤, 많이

[^26]: **もうちょっと** : "조금 더" → 더 많은 양이나 정도를 표현할 때 사용

[^27]: **できる (できる, dekiru)** : 할 수 있다
