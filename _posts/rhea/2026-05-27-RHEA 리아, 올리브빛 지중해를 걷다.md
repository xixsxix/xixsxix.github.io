# 01 촬영 개요

이번 촬영은 하나의 의상을 중심으로 지중해 해안 마을을 따라 이동하는 흐름을 가진 여름 시네마틱 에디토리얼 세트다.  
도착 장면에서 시작해 골목, 계단, 카페, 올리브 가든, 바다 전망 테라스, 마지막 클로징 컷까지 이어지는 구조로 구성했다.

- 캐릭터: 리아 / Rhea
- 콘셉트: 지중해 여름 여행 에디토리얼
- 무드: sage / olive / ivory 중심의 조용하고 우아한 여름 감성
- 구성 방향: 전신 중심 의상 가독성 + 장소 변화에 따른 스토리 진행 + 마지막 감정 클로징

# 03 환경 정보

## 환경 흐름
1. 햇살이 비치는 도착 길
2. 좁은 지중해 골목
3. 흰 돌계단 구간
4. 해안 카페 테라스
5. 올리브 가든 산책로
6. 바다 전망 테라스
7. 골든아워 클로징 테라스

## 환경 키워드
- Mediterranean coastal town
- pale stone / cream plaster / textured beige wall
- blue sea / bright horizon / summer air
- olive trees / soft wild greenery
- warm reflected sunlight / golden-hour shadow
- quiet cinematic summer atmosphere

# 04 의상 정보

## 상의
- 올리브/세이지 톤의 비대칭 시어 탑
- 비대칭 네크라인

- 얇고 투명한 소재감

- 몸에 부드럽게 감기는 핏

## 하의

- 세로 흐름이 살아 있는 주름감
- 바람을 받으면 자연스럽게 퍼지는 길이감
- 하단부에 올리브/세이지 워터컬러 느낌의 패턴 흐름

## 액세서리

# 06 AI Creative Director 평가

## 전체 총평
이번 촬영은 같은 의상을 유지한 상태에서 환경을 단계적으로 바꾸면서 스토리를 만들자는 방향이 잘 구현된 세트다.  
이전처럼 비슷한 배경과 비슷한 포즈 반복으로 보이지 않고, “도착 → 이동 → 머묾 → 산책 → 감정 클로징”의 흐름이 비교적 명확하게 완성됐다.

## 강점
- 얼굴 정체성 유지가 전반적으로 안정적
- 의상 색감과 지중해 환경의 조합이 자연스럽다
- 상의의 시어 질감과 스커트의 길이감이 여러 컷에서 잘 살아남
- Shot 01, 04, 06, 07이 각기 다른 용도로 확실히 쓸 수 있다
- 블로그 / 유튜브 / 인스타그램 재사용성이 높다

## 컷별 평가
- Shot 01: 강력 사용  
  - 오프닝 컷으로 매우 좋음
  - 전신 가독성 우수
- Shot 02: 강력 사용  
  - 이동감과 골목 무드가 좋음
  - 스토리 진행용으로 적합
- Shot 03: 사용 가능  
  - 계단을 활용한 길이감 표현이 좋음
  - 실루엣 확인용 보조컷으로 유효
- Shot 04: 강력 사용  
  - 라이프스타일 무드가 가장 자연스럽게 살아남
  - 블로그 본문 / 유튜브 중간 포인트 컷으로 좋음
- Shot 05: 사용 가능  
  - 자연 전환 컷으로 좋음
  - 감정 호흡을 만들어 주는 역할
- Shot 06: 강력 사용  
  - 이번 세트의 대표 메인컷
  - 바다 배경과 감정선이 가장 잘 맞음
- Shot 07: 강력 사용  
  - 클로징 / 썸네일 / 감정 마무리용으로 최적
  - 표정 활용도가 높음

# 08 제작 메모

- 이번 세트는 “같은 의상 + 다른 장소 + 서사형 흐름”이라는 방향이 잘 맞았다.
- 좁은 골목, 계단, 카페, 가든, 전망대까지 환경 변화가 분명해서 콘텐츠 완성도가 올라갔다.
- Shot 06과 Shot 07은 서로 역할이 다르다.
  - Shot 06 = 메인 대표컷
  - Shot 07 = 감정 클로징 / 썸네일 컷
- 이후 비슷한 방식의 촬영을 진행할 때도 “이동 동선이 느껴지는 환경 시퀀스” 구조를 계속 활용할 가치가 크다.
