# Overseas News Clipping_Feat.ChatGPT

**perplexity.ai**에서 스크랩 한 후 **ChatGPT**에 제공

```perplexity.ai
Collect recent global news from the last 24–48 hours.

Requirements:

- Provide 12–20 news items
    
- Use diverse, high-credibility sources
    
- Include at least 5 different outlets (Reuters, AP, BBC, Bloomberg, FT, WSJ, Al Jazeera, etc.)
    
- Prioritize factual reporting over opinion/editorials
    
- Avoid duplicates (same event from same source)
    
- Limit to a maximum of 2–3 articles per same event
    
- Ensure diversity of topics across the dataset
    

Time Constraint:

- Only include articles published within the last 48 hours
    
- Exclude older articles even if highly relevant
    

Link Quality:

- Ensure links are direct article URLs (not AMP, redirects, or aggregated pages)
    

For each item, use this exact format:

[Source]  
Outlet: (e.g., Reuters, BBC)  
Title: (original headline)  
Summary: (2–3 sentences, factual only, no interpretation)  
Published: (time or date if available)  
Link: (direct URL)

Rules:

- Keep summaries neutral and concise
    
- Do NOT merge or analyze articles
    
- Do NOT cluster events
    
- If multiple sources report the same event, list them separately (within the 2–3 limit)
    
- Preserve source identity clearly for each item
    

Goal:  
Produce a clean, structured dataset of news articles ready for multi-source analysis.
```
