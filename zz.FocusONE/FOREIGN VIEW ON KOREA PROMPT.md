# FOREIGN VIEW ON KOREA PROMPT

```perplexity.ai
Collect international news that mention South Korea.

Time Scope:

- Yesterday Window:  
    Collect news published between 00:00–23:59 (KST) of the previous day
    
- Today Live Window:  
    Collect news published from 00:00 (KST) today up to the current time
    

Rules:

- Clearly separate yesterday and today items
    
- Do NOT mix the two time windows
    
- Avoid duplicate reporting of the same event across both windows
    

Scope:

- ONLY non-Korean (foreign) media
    
- Focus on how South Korea is covered globally
    

Requirements:

- Provide 25–35 issues
    
- Avoid duplicates
    
- Limit 2–3 items per same event
    
- Ensure diversity of topics
    

Source Strategy:

- Use major global outlets (Reuters, AP, BBC, Bloomberg, FT, WSJ, Al Jazeera, etc.)
    

South Korea Relevance:

- Must be meaningful involvement (not passing mention)
    

Output Format:

[Yesterday]

[Category]

(Explain Korea involvement + context)

(1 line about global positioning)

[Category]

(Explain Korea involvement + evolving situation)

(1 line)

Rules:

- Do NOT include Korean domestic media
    
- Keep summaries neutral and factual
```
