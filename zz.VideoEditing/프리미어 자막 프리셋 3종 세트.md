# 🎬 1. 기본 자막 프리셋 (메인)

👉 대부분 상황에서 쓰는 “기본값”

### 📌 텍스트

- 폰트: S-Core Dream
- 두께: **Bold (700)**
- 크기: **60~70**
- 색상: #FFFFFF

### 📌 스트록

- 켜기 ✔
- 색상: #1A1A1A
- 두께: **2.5**

### 📌 그림자 (Shadow)

- 켜기 ✔
- 색상: #000000
- 투명도: **70%**
- 거리: **2**
- 블러: **8**
- 각도: 120°

### 📌 위치

- 하단 중앙
- Safe Margin 안쪽 (너무 아래 X)

👉 💡 특징  
“어디서든 안정적으로 잘 보이는 무난 최강 세팅”

# 🎬 2. 강조 자막 프리셋 (임팩트용)

👉 중요한 단어 / 웃긴 포인트

### 📌 텍스트

- 폰트: S-Core Dream
- 두께: **ExtraBold (800)**
- 크기: **70~80**
- 색상:
    - 기본: #FFFFFF
    - 강조: #FFD400 (노랑 추천)

### 📌 스트록

- 색상: #000000
- 두께: **3**

### 📌 그림자

- 투명도: **80%**
- 거리: **3**
- 블러: **10**

👉 💡 특징  
“확실하게 튀어나오는 느낌”  
(남발 금지 — 포인트용)

---

# 🎬 3. 부드러운 설명 자막 (서브용)

👉 차분한 설명, 정보 전달

### 📌 텍스트

- 폰트: S-Core Dream
- 두께: **Medium (500)**
- 크기: **55~60**
- 색상: #FFFFFF

### 📌 스트록

- 색상: #2B2B2B
- 두께: **2**

### 📌 그림자

- 투명도: **60%**
- 거리: **2**
- 블러: **6**

👉 💡 특징  
“튀지 않지만 깔끔하게 읽힘”

---

# 🎯 추가 핵심 세팅 (이거 진짜 중요)

### ✔ 자간 (Tracking)

- 0 ~ +10  
    👉 너무 붙어있으면 답답해 보임

---

### ✔ 행간 (Leading)

- 자동 or 약간 여유  
    👉 두 줄 이상일 때 필수

---

### ✔ 정렬

- 무조건 **가운데 정렬**  
    👉 유튜브는 이게 제일 안정적

---

# 🛠 프리미어에서 저장 방법

1. 텍스트 하나 만든다
2. 위 설정 그대로 적용
3. 우클릭 → **"Create Style (스타일 만들기)"**
4. 이름:
    - Subtitle_Main
    - Subtitle_Impact
    - Subtitle_Sub

👉 그러면 다음부터 클릭 한 번으로 끝

---

# 🔥 마지막 핵심 한 줄

👉 “Bold + 얇은 스트록 + 부드러운 그림자”  
이 조합이 유튜브 가독성 거의 정답이다.
