## 🎬 영상에서 많이 쓰는 색상 원칙

유튜브든 방송이든 공통적으로 이렇게 감:

👉 **“기본 + 강조 + 배경” 3개 구조**

---

## 🔥 1. 가장 많이 쓰는 기본 조합

### ✅ 블랙 + 화이트 + 포인트 1색

- ⚫ 블랙 → 배경 / 안정감
- ⚪ 화이트 → 기본 텍스트
- 🔴 포인트 컬러 → 강조

👉 이게 거의 **유튜브 표준 조합**

---

## 🎯 포인트 컬러 추천 (중요)

영상에서 많이 쓰는 색 몇 개 찍어줄게:

### 🔴 레드 (가장 많이 씀)

- 긴박감 / 강조 / 클릭 유도
- 예: “위험”, “핵심”, “주의”

👉 유튜브 느낌 가장 강함

---

### 🔵 블루

- 신뢰 / 깔끔 / 정보 전달
- IT, 설명 영상에 잘 맞음

---

### 🟡 옐로우 (강력 추천)

- 눈에 확 띔
- 자막 강조에 최고

👉 검정 배경 + 노랑 텍스트 = 가독성 최강

---

### 🟢 그린

- 성공 / 긍정 / 완료 느낌
- 게임 / 상황 설명에 좋음

---

## 🎨 너한테 추천 조합 (현실적으로)

너 지금

- 게임 영상 + 개그 + 자막 스타일

👉 이거면 이게 베스트임:

### ⭐ 추천 세트

- 배경 → #000000 (블랙)
- 기본 텍스트 → #FFFFFF (화이트)
- 강조 → #FFD400 (노랑)

👉 이거 진짜 많이 씀 (가독성 미침)

---

## 💡 한 단계 더 (프로 느낌)

포인트 색 하나 더 추가:

- 🔴 #FF3B3B → 강한 강조 (웃긴 타이밍, 충격)
- 🟡 #FFD400 → 일반 강조

👉 이렇게 2단계 강조 쓰면 훨씬 고급짐

---

## ❌ 초보들이 많이 하는 실수

- 색 5개 이상 씀 → ❌
- 파스텔톤 남발 → ❌ (영상에서 흐려짐)
- 배경 밝은데 텍스트도 밝음 → ❌

👉 무조건 대비가 핵심

---

## 🎬 진짜 중요한 팁 (이건 꼭 써먹어)

👉 “색보다 더 중요한 건 일관성”

- 모든 영상에서 같은 색 쓰기
- 같은 의미 = 같은 색

예:

- 노랑 → 강조
- 빨강 → 위험 / 웃긴 포인트

👉 이거 쌓이면 “브랜드”됨

---

## 🔥 한줄 정리

👉 **블랙 + 화이트 + 노랑(강조) + 빨강(강조2)** 이거면 유튜브 상위 80% 스타일 완성
