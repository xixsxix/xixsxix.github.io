# 실전 숏폼 마스터 커리큘럼 .feat ChatGPT

좋다. 이건 그냥 “기능 설명 강의”가 아니라 **진짜 혼자서 쇼츠를 만들 수 있게 만드는 커리큘럼**으로 설계해볼게. 실무 흐름 그대로 간다.

---

# 🎬 전체 커리큘럼 개요

## 🟢 Beginner (입문) — “처음부터 영상 하나 완성”

**목표:** 컷 편집 + 자막 + 간단 효과로 1개의 영상 완성

1. 프리미어 기본 인터페이스 & 작업 흐름
    
2. 영상 가져오기 & 타임라인 이해
    
3. 컷 편집 (자르기 / 붙이기)
    
4. 자막 넣기 (기초)
    
5. 전환 효과 & 간단 효과
    
6. 오디오 기본 조절
    
7. 내보내기 (Export)
    
8. 🎯 미니 프로젝트 (30초 영상 제작)
    

---

## 🟡 Intermediate (중급) — “쇼츠 콘텐츠 제작”

**목표:** 유튜브 쇼츠 1개 완성 (스토리 + 템포 + 스타일)

1. 쇼츠 구조 이해 & 기획
    
2. 편집 리듬 & 템포 만들기
    
3. 자막 스타일링 (가독성 + 강조)
    
4. B-roll 활용
    
5. 기본 색보정 (Color Correction)
    
6. 오디오 믹싱 (음악 + 음성)
    
7. 키프레임 기초 (움직임)
    
8. 템플릿 활용
    
9. 프록시 (저사양 최적화)
    
10. 🎯 쇼츠 프로젝트 제작
    

---

## 🔴 Advanced (고급) — “빠르고 프로처럼”

**목표:** 빠른 제작 + 고퀄 영상 + 포트폴리오

1. 고급 색보정 (Color Grading)
    
2. 키프레임 애니메이션 심화
    
3. 효과 조합 (시네마틱 / 글리치 등)
    
4. 사운드 디자인
    
5. 멀티캠 편집
    
6. 템플릿 제작 (재사용 구조)
    
7. 프리셋 & 자동화
    
8. 속도 최적화 (실무 워크플로우)
    
9. 🎯 포트폴리오 프로젝트
    

---

# 🟢 Beginner 단계 (상세)

---

## 1. 프리미어 기본 인터페이스 & 작업 흐름

**목표:** 프로그램 구조를 이해하고 “어디서 뭐 하는지” 알기

**핵심 개념**

- Project / Source / Program / Timeline
    
- Workspace (Editing, Color 등)
    
- 파일 기반 작업 흐름
    

**실습 단계**

1. 프리미어 실행 → Editing 워크스페이스
    
2. 패널 위치 확인
    
3. 패널 드래그로 레이아웃 변경
    
4. Workspace 저장
    

**과제**

- 나만의 작업 레이아웃 만들기
    

**Pro Tip**

- 저사양: Playback Resolution → 1/2 또는 1/4
    

---

## 2. 영상 가져오기 & 타임라인 이해

**목표:** 영상 파일을 불러와 타임라인에 올리기

**핵심 개념**

- Import vs Drag & Drop
    
- Sequence 자동 생성
    
- 트랙 구조 (V1, A1)
    

**실습**

1. 영상 파일 Import
    
2. 드래그 → 타임라인
    
3. 시퀀스 자동 생성 확인
    

**과제**

- 3개 영상으로 타임라인 구성
    

**Pro Tip**

- 파일명 정리 안 하면 나중에 지옥됨
    

---

## 3. 컷 편집 (자르기 / 붙이기)

**목표:** 불필요한 부분 제거

**핵심**

- Razor Tool (C)
    
- Ripple Delete
    
- Trim
    

**실습**

1. 침묵 구간 자르기
    
2. 불필요한 장면 제거
    
3. 자연스럽게 붙이기
    

**과제**

- 1분 영상 → 30초로 줄이기
    

**Pro Tip**

- Q / W 키로 빠른 컷팅 가능 (속도 핵심)
    

---

## 4. 자막 넣기 (기초)

**목표:** 기본 자막 추가

**핵심**

- Text Tool
    
- Essential Graphics
    
- 폰트 / 크기 / 위치
    

**실습**

1. 자막 추가
    
2. 위치 조정
    
3. 간단 스타일 적용
    

**과제**

- 영상 전체에 핵심 자막 넣기
    

**Pro Tip**

- 자막은 “읽히는 게 전부” → 디자인보다 가독성
    

---

## 5. 전환 효과 & 간단 효과

**목표:** 기본적인 영상 연결

**핵심**

- Cross Dissolve
    
- Dip to Black
    
- Scale / Position
    

**실습**

1. 컷 사이에 효과 넣기
    
2. 간단 줌 효과 적용
    

**과제**

- 3가지 전환 사용 영상 만들기
    

**Pro Tip**

- 전환 남발하면 초보 티 남
    

---

## 6. 오디오 기본 조절

**목표:** 소리 깨끗하게 만들기

**핵심**

- Volume 조절
    
- Gain
    
- Background noise 최소화
    

**실습**

1. 음량 균일화
    
2. 배경음 줄이기
    

**과제**

- 일정한 볼륨 유지 영상 만들기
    

**Pro Tip**

- -6dB ~ -3dB 유지
    

---

## 7. 내보내기 (Export)

**목표:** 영상 완성 파일 출력

**핵심**

- H.264
    
- 해상도 (1080x1920 for Shorts)
    
- Bitrate
    

**실습**

1. Export 설정
    
2. 파일 출력
    

**과제**

- 쇼츠 규격 영상 출력
    

**Pro Tip**

- YouTube preset 활용
    

---

## 8. 🎯 미니 프로젝트

**목표:** 하나의 완성 영상 만들기

**과제**

- 30초 영상 제작
    
- 컷 편집 + 자막 + 기본 효과 포함
    

**Pro Tip**

- “완성” 경험이 가장 중요
    

---

---

# 🟡 Intermediate (핵심만 압축)

---

## 핵심 변화

👉 “편집” → “콘텐츠 제작”

---

## 주요 포인트

### 편집 리듬

- 컷 길이 = 집중도
    
- 음악 비트 맞추기
    

### 자막 스타일링

- 키워드 강조
    
- 색상 대비
    

### B-roll

- 지루함 제거 핵심 요소
    

### 색보정

- 노출 / 대비 / 화이트밸런스
    

### 오디오 믹싱

- 음악 -20dB / 음성 -6dB
    

### 키프레임

- 줌 인 / 패닝
    

### 프록시

- 저사양 필수
    

---

## 🎯 중급 프로젝트

**“유튜브 쇼츠 1개 제작”**

구성:

1. Hook (3초)
    
2. 본문
    
3. 클라이맥스
    
4. 마무리
    

---

---

# 🔴 Advanced (핵심만 압축)

---

## 핵심 변화

👉 “편집자” → “제작자”

---

## 주요 포인트

### 색보정 심화

- LUT 활용
    
- 시네마톤
    

### 키프레임 애니메이션

- 자연스러운 움직임 (Ease In/Out)
    

### 효과 조합

- 글리치 + 라이트 리크 + 그레인
    

### 사운드 디자인

- 효과음 타이밍
    

### 자동화

- 프리셋 저장
    

### 속도 최적화

- 단축키 커스터마이징
    
- 반복 작업 제거
    

---

## 🎯 최종 프로젝트

**포트폴리오용 쇼츠 3개 제작**

- 스타일 3가지
    
- 빠른 편집
    
- 브랜드 느낌 유지
